# AI-Based Forest Fire Detection

## Overview
Real-time fire detection system using computer vision.

## Problem
Detect fire early from image or video feeds.

## Solution
Use a computer vision pipeline with YOLOv8 and OpenCV to identify fire-like regions.

## Technologies
- Python
- YOLOv8
- OpenCV

## Features
- Real-time detection
- Computer vision based analysis
- Easy extension for new datasets

## How to run
1. Add the project code and required model files.
2. Install the project dependencies.
3. Run the main script or notebook for detection.
